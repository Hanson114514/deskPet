# task11 · 设置窗口：五行设置、改完立即生效、绝不显示假成功

## 1. 背景

- **task01–10 已完成**：窗口、配置与日志、素材加载（含坏包校验）、10 级尺寸与控制栏、
  动画、右键菜单（含镜像）、拖动与命中、久置行为、音效与双击手势。
- 目前所有配置都要手改 `config.json`。本 task 提供**设置窗口**，
  并把已有能力按"数据驱动"的方式暴露出来。
- 这是旧框架痕迹**最重**的一节（自绘控件、绝对坐标、靠"把窗口调高"避免截断），
  所以**必须按 Qt 的方式重做**（见 `迁移清单.md` 第一部分 §15 的标注）。

> **开始前必须先读**：`agent.md`（配置字段表、错误处理方式、信号命名规则）、
> `迁移清单.md` 第一部分 §15（设置窗口**全部条目** + PySide6 标注）、
> 第二部分 §4（配置通用规则）、第三部分 3.4（AltGr）/ 3.5（两套修饰键掩码）/
> 3.13（读状态不能顺手写盘）/ 3.15（失败必须带出原因）、附录 B（全部可见文字）。

## 2. 本任务目标

运行后能看到：

1. 右键 `设置…` → 打开标题为 **`桌宠设置`** 的窗口，**水平居中、垂直约 1/3 处**；
2. 三组五行，顺序固定：

   | 分组 | 行 | 控件 |
   | --- | --- | --- |
   | 常规 | `角色`（提示：换一个形象；切换需要重启桌宠（会自动问你要不要现在重启）） | 下拉（**候选可包含坏包**） |
   | 常规 | `开机自启`（登录 Windows 后自动启动桌宠） | 勾选（**本 task 先禁用并标注"（暂未开放）"**） |
   | 常规 | `呼出快捷键`（隐藏后按此键呼出；点右边按钮后按一次想要的组合） | 按键录入（**本 task 先禁用并标注"（暂未开放）"**） |
   | 声音 | `音量`（点击互动与坐下时的音效音量） | 滑块 0–100（单位空） |
   | 行为 | `久置时间`（鼠标静止这么久后开始张望，再过一半时间坐下） | 滑块 5–300（单位 ` 秒`） |

3. **拖动音量滑块 → 立刻听到音量变化**；**拖动久置时间滑块 → 立刻影响判定**；
   两处都**立刻写回配置**；
4. 点 `关闭` 或按 `Esc` 都能关闭窗口，关闭后**再打开正常**（实例引用已释放）；
5. 打开设置窗口时**只读不写**：即使写路径被破坏（把 `data/` 设成只读），
   打开设置**也不报错**、也不改任何文件（§3.13）；
6. 反复点 `设置…` → **只有一个设置窗口**，再次点击把已有的**前置**；
7. 设置窗口**按住输入焦点**（模态），点旁边不会误操作宠物；
8. 左下角有 **`打开启动文件夹`** 逃生门按钮（本 task 只要求"能打开那个文件夹"，不接自启）；
9. 窗口底部有**状态栏**；写入失败时状态栏显示 `设置失败：<系统原因>`，
   并且**控件值立刻回滚**（绝不显示假成功）；
10. 角色下拉里：**所有发现的包都列出来**（坏的也列，标注 `⚠ 不可用`），
    当前生效的那个标 `● `，文字形如 `菲比（phoebe-2）`。

## 4. 接口约定

### 字段描述表（**单一真相源**）

| 符号 | 语义 |
| --- | --- |
| `FIELDS: tuple[FieldSpec, ...]` | 有序；`FieldSpec` 含 `group` / `key` / `title` / `hint` / `kind` / 量程 / 单位 / 是否已实现 |
| `FieldKind` | `COMBO`（角色）/ `CHECK`（自启）/ `KEYSEQ`（快捷键）/ `SLIDER`（音量、久置时间） |
| 行顺序 | **即界面顺序**（数据驱动，不在界面代码里手写顺序） |
| 未实现的项 | `setEnabled(False)` + 标题追加 `（暂未开放）`，**不是隐藏**（保持布局稳定） |

| 项 | 约定 |
| --- | --- |
| 窗口尺寸 | **560 × 516 逻辑单位**；**必须够高**的问题在 Qt 下用
`setMinimumSize` + **内容区 `QScrollArea`** + `QDialogButtonBox` 从根上消除（**不要**靠调大数字） |
| 布局 | **`QVBoxLayout` + 每组一个 `QGroupBox` + 组内 `QFormLayout`**；**不要**绝对坐标 |
| 居中 | 水平居中、垂直约 1/3 处 |
| 单例 | 同一时间**只允许一个**；重复打开 → 把已有的**前置** |
| 模态 | 设置期间抓住输入焦点 |
| 关闭 | 窗口关闭按钮 + `Esc`；关闭后**释放实例引用** |
| 改完立即生效 | 滑块变化立刻作用到运行时并写回配置 |
| 勾选失败回滚 | 写入失败 → **控件恢复原样** + 状态栏 `设置失败：<系统原因>`；
**必须屏蔽信号/加守卫**，否则"回滚赋值"会再触发一次写入（Qt 新引入的回路风险） |
| 状态栏 | 打开时、每次改动后刷新；**`error` 存在时失败原因优先于状态本身** |
| 角色候选 | 列出**所有**发现的包（坏的也列 + `⚠ 不可用`）；当前生效的标 `● ` |
| 角色选项文字 | `展示名（命名空间）`，坏的追加 `　⚠ 不可用` |
| 角色按钮文字 | 优先展示名（按钮宽度放不下长名字），完整命名空间放状态栏 |
| 逃生门 | `打开启动文件夹` **必须在左下角、随手可及** |
| 已删除的开关 | 「始终置顶」与「记住位置与大小」**不得**再出现 |
| `mirror` 字段 | **不在设置窗口里**；但"只保存已知键"的过滤**必须认得它**，不能当未知键丢掉 |

### 快捷键录入（`deskpet.keycapture`，本 task 只建骨架）

- 点按钮进入录入态 → 按一次组合即录入；**Esc 取消**；修饰键**单独按下不算**；
  **至少一个修饰键**；成功/失败都要给一句话；失败保留原快捷键；
- **判定以"实测按下的按键"为准，不看 `event.modifiers()`**（§3.4：AltGr 会被报成 Alt）；
- 录入中实时显示已按下的修饰键 + `…`；
- 展示顺序固定 `Ctrl → Alt → Shift → Win`；
- 本 task **禁用**该行（自启与热键的实际功能在 task12/task14）。

### 错误处理（本 task 必须定型的项目级约定）

- **写操作失败必须报错并带出系统原因**（`OSError` 的原始信息），**不许 `except OSError: pass`**；
- 读操作**只读**，失败也不能顺手自愈、不能写盘；
- 结果用**结构化对象**表达（`ok` / `error` / `detail`），界面**渲染时**决定"error 优先"，
  **不要**在拼接字符串时决定（"显示假成功"就是这么来的）。

- ❌ 不实现"开机自启"的实际功能（task14；本 task 只让那一行**禁用并标注**）
- ❌ 不实现"呼出快捷键"的实际注册（task12；本 task 只建控件骨架并禁用）
- ❌ 不做"换角色 → 问是否重启"的完整流程（重启能力在 task13；
      本 task 里角色下拉**可以改配置**，但"询问重启"要先做成"重启后生效"的提示，
      并在 agent.md 里记下"完整流程待 task13 接线"）
- ❌ 不做单实例保护 / 自启 / 热键注册 / 隐藏呼出
- ❌ 不做主题、不做深色模式、不做多语言
- ❌ 不引入第三方 UI 库（不要 qfluentwidgets 之类）
- ❌ 不把"未实现项"隐藏掉
- ❌ 不在界面代码里手写行顺序或控件类型（必须走字段描述表）
