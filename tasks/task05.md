## 2. 本任务目标

运行后能看到：

1. `python run.py` 启动后，宠物**持续播放 `idle`**：站立呼吸 + 眨眼，
   节奏是**每帧约 125 ms**（当前三个包没写 `fps`，命中遗留兜底的 8.0 fps）；
2. 手工给 `assets/phoebe-2/asset.json` 的 `actions.idle` 加 `"fps": 24` 后重启，
   `idle` **明显变快**（约 41.7 ms/帧）；改成 `"fps": 0.5` 后重启，**明显变慢**（2 秒一帧）；
3. `python run.py --action jumping`：跳跃**只播一遍**，停在**末帧落地站姿**不动；
   `python run.py --action running-right`：**往返播放**（到末端折返回来），不会突然跳回第一帧；
   `python run.py --action sit`：**单向循环**（末帧接首帧连续，不倒着转）；
4. 用 `--action 不存在的动作` → **明确报错并列出可用动作**（不是静默换成 idle）；
5. 启动期间 UI **不卡**：拖动窗口、点菜单（如果有）都有响应（动画不是阻塞式死循环）。

## 4. 接口约定

### 播放方式（**唯一真相源**，写在 `animation.py`）

| 动作 | 播放方式 | 结束行为 |
| --- | --- | --- |
| `idle` | **单向循环** | 永不到头 |
| `running-left` | **往返** | 永不到头 |
| `running-right` | **往返** | 永不到头 |
| `jumping` | **一次性** | 播到**末帧即停**（不再推进） |
| `waiting` | **往返** | 永不到头 |
| `sit` | **单向循环** | 永不到头（**不往返**：剪成刚好一圈才连续） |

- 动作名**以素材 `actions` 的键为准**（`idle` / `running-left` / `running-right` /
  `jumping` / `waiting` / `sit`）；**不要再引入 `review` / `rest` 别名**（见清单 §2 的修订说明）。

### `Animation`（`deskpet.animation`）

| 成员 | 语义 |
| --- | --- |
| `Animation(spec, action="idle", fps_override=None)` | 构造；`fps_override` 只用于调试，**不写回配置** |
| `frame_ms -> float` | 当前动作的每帧毫秒（**来自 task03 的解析结果**，本模块不重复解析、不重复告警） |
| `mode -> {"loop", "pingpong", "oneshot"}` | 由播放方式表决定 |
| `index -> int` | 当前帧序号 |
| `advance() -> int \| None` | 推进一帧；返回**下一次换帧需要的毫秒数**；**定格时返回 `None`**（不排下一次） |
| `set_action(action: str)` | 切换动作；动作不存在 → **抛错并列出可用动作**；切换会**中断正在播的片段序列** |
| `hold(index: int)` / `release_hold()` | 定格/解除定格；**越界帧号必须报错** |
| `play_sequence(segments)` | 片段序列（见下） |
| `sequence_done` 信号 | 片段序列播完时发出（供 task10 的双击跳跃回 idle 用） |

**片段**：`(动作, 帧区间或 None, 结束方式)`；结束方式 `"auto"` 或 `("loop", N)`：

- `"auto"`：随动作默认行为（一次性动作播到末帧即止；循环动作永不结束）；
- `("loop", N)`：N 是**完整圈数**；一圈 = **回到起点帧且方向朝前**；
  往返播放的一圈包含**两个折返点**，**不能按"到达末端"计次**（会把圈数算成两倍）；
- 切片区间**越界要夹住**，不能画出空白；
- 切换动作**中断**正在播的片段序列。

### 调度（**本 task 的关键设计点**）

- 动画由 **`QTimer`** 驱动，**每帧结束后按 `advance()` 的返回值重新排下一次**
  （`setInterval` / `start(next_ms)`）；
- **不是**固定 16 ms 空转；
- dt 上限 **100 ms**（夹住休眠唤醒后的异常增量，避免动画跳变）；
- 调度间隔边界：下限 **4 ms**（防忙等）、上限 **250 ms**（保证退出/信号被及时处理）；
- `advance()` 返回 `None`（定格）→ **不 `start()` 定时器**；
- `QTimer` **不保证准点**：不要写"每 83 ms 加一帧"这种假设（`frame_ms` 可能是小数），
  抖动要么用绝对时间差吸收，要么像"算完一帧再重排"这样自然累积；
- **不要**用 `QThread`、`QThreadPool` 或任何后台线程做这件事（GUI 线程足够，且 `QPixmap` 只能在 GUI 线程用）。

### 命令行（本 task 新增）

| 参数 | 约定 |
| --- | --- |
| `--action 动作` | 缺省 `idle`；可选值 = **素材里真实存在的动作**（从 `actions` 键推导，**不要另写一张写死的表**） |
| `--fps` | **已删除，不得复活**（帧率由素材决定） |

- 启动信息里必须打印：动作 + 每帧毫秒 + **帧率来源**（`asset.json` / 遗留兜底 / 默认 12）。

## 6. 验收标准

- [ ] 启动后 `idle` 持续循环，**肉眼节奏约 8 fps（每帧约 125 ms）**；

- [ ] `--action running-left` / `running-right` 往返播放：
      **到末端折返**、**不出现"末帧直接跳到首帧"的突跳**
- [ ] `--action sit` 单向循环：**接缝处连续**，不倒着转
- [ ] `--action waiting` 往返播放（低头再抬头往复）
