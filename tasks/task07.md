# task07 · 久置行为：鼠标一停就张望，再等一会儿坐下

## 1. 背景

- **task01–06 已完成**：窗口、配置与日志、素材加载、尺寸档位、动画、右键菜单（含镜像翻转）。
- 现在只能靠右键菜单手动切动作。本 task 加入**自动姿势状态机**：
  鼠标长时间不动 → 张望（`waiting`）→ 再等一半时间 → 坐下（`sit`）；
  鼠标一动 → 站起来回到 `idle` 并重新计时。
- 右键菜单里的 `坐下休息` / `站起来` 在本 task 里获得**正式语义**（`manual` 模式）。
- **本 task 之后才是拖动（task08）**，所以本 task **不要**依赖拖动逻辑；
  拖动中的交互留好接口即可（见"不要做"）。

> **开始前必须先读**：`agent.md`（`idle_seconds` 与 `mirror` 字段）、
> `迁移清单.md` 第一部分 §7（静置行为与姿势状态机的**全部**常量与例外）、
> §9（镜像适用范围是 `idle` / `waiting` / `sit`）、附录 C 的 `MOUSE_MOVE_EPSILON` /
> `REST_SIT_MIN_S` / `REST_SIT_RATIO` / `idle_seconds` 三行。

## 2. 本任务目标

运行后能看到：

1. 启动后宠物站着（`idle`）；**鼠标静止 20 秒**（配置 `idle_seconds` 默认 20）→ 宠物开始**张望**（`waiting`）；
2. 再静止 **10 秒**（`max(5, 20 × 0.5)`）→ 宠物**坐下**（`sit`）；
3. 期间**鼠标一动**（哪怕是移出宠物窗口，在别的程序上动）→ 宠物立刻**站起来**回到 `idle`，
   并**重新开始计时**（再等 20 秒才张望）；
4. 改 `config.json` 里的 `idle_seconds` → **不用重启**，下一次判定就用新值；
5. 点右键菜单的 `坐下休息`（`manual` 模式）→ 宠物一直坐着：
   **鼠标怎么动、等多久都不影响它**；菜单文字变 `站起来`；
   再点那次菜单 → 站起来，回到 `auto` 模式；
6. `manual` 坐姿期间**双击宠物** → 自动退出 `manual` 模式（跳起来）。
   （拖动退出 `manual` 在 task08 接线；本 task 只需把接口留好。）

## 4. 接口约定

### 状态机（`deskpet.idle_state`，**纯逻辑、可脱离窗口测**）

| 符号 | 语义 |
| --- | --- |
| `Stage` | 状态常量：`IDLE` / `WAITING` / `SIT`（**与动作名同形**：`idle` / `waiting` / `sit`） |
| `IdleStateMachine(idle_seconds_provider)` | `idle_seconds` 通过**回调/读取函数**取得，**不在构造时快照** |
| `on_mouse_moved()` | 鼠标动了：**重置计时**；从 `WAITING`/`SIT` 站起回 `IDLE` |
| `on_tick(now)` | 计时推进；到点则升级阶段 |
| `enter_manual()` / `exit_manual()` | 主动坐姿（`manual` 模式） |
| `stage_changed(old, new)` 信号 | 阶段变化时发出（上层据此切动作） |
| `timer_reset` 信号 | "只归零、不切动作"时发出（**与 `stage_changed` 分开**） |

**常量与规则（逐条实现）**：

| 常量 / 规则 | 值 / 说明 |
| --- | --- |
| `MOUSE_MOVE_EPSILON` | **2 px**：位移**平方**与阈值比较；光标静止时的 1px 抖动不算"动了" |
| 首次观察光标 | 按"**没动**"处理（第一次看到光标不等于光标动了） |
| `REST_SIT_MIN_S` | **5 秒**：坐下等待的下限 |
| `REST_SIT_RATIO` | **0.5**：用户只看到一个"久置时间"，坐下必须由它推导 |
| `idle_seconds` 读法 | **每次判定时读配置**（改完立刻生效，不该等重启） |
| `idle_seconds` 兜底 | 配置坏了用 **20 秒**；取值**下限 1 秒**（静置行为不能因配置问题失效） |
| `auto` 模式 | 鼠标动 → `idle`；静置 `T` → `waiting`；再静置 `S = max(5, T × 0.5)` → `sit`；鼠标再动 → 重新站起并重新计时 |
| `manual` 模式 | 鼠标移动、久置计时都**不影响**它；退出方式：**拖动 / 双击 / 再次点菜单** |
| **两个例外** | 计时都要归零，但**不强行切动作**：① **主动坐姿**（点菜单不该把它拽起来）；② **拖动中**（动作由拖动逻辑按方向播跑动，这里插手会闪一下）。**本 task 只做例外①**；例外②的接线点在 task08，本 task 必须**暴露一个"当前是否被外部占用动作控制权"的开关**（例如 `set_suspended(bool)`），供拖动调用 |

### 光标监视（`deskpet.cursor_watch`）

| 符号 | 语义 |
| --- | --- |
| `CursorWatch(interval_ms=150)` | 独立 `QTimer`，每次 tick 读 `QCursor.pos()` |
| `moved` 信号 | 位移平方 > `2²` 时发出（**首帧不算**） |
| `pos` 记录 | 自己记"上次位置"，**不要**依赖窗口的 `enterEvent`/`leaveEvent` |

**为什么必须读全局光标**：鼠标在窗口**外面**移动时收不到事件，而久置判定要按**全屏鼠标活动**计算。
**为什么轮询是允许的**：全屏鼠标活动**没有信号可订阅**——但**计时本身**必须由状态机 + 定时器表达，
**不要**把"计时"写成"每个动画帧减一次"（清单 §7 的 PySide6 标注）。

### 与动画/镜像的关系

- 阶段 → 动作名的映射：`IDLE → idle`、`WAITING → waiting`、`SIT → sit`（**同名**，便于镜像按状态记忆）；
- 切到某个阶段时，**按该动作的镜像记忆**决定是否翻转（task06 已实现，本 task 只需调用）；
- **被挂起时不要切动作**（例外的第②条），由上层传入的挂起标志决定。

### 右键菜单

- `action` 项（`坐下休息` / `站起来`）现在**真正接线**：
  点它进入/退出 `manual` 模式，并**重置静置计时**；
- 菜单文字按 `manual` 状态变化（task06 已有文字切换，本 task 接上状态）。

## 5. 不要做

- ❌ **不做拖动**（拖动、命中判定、位置持久化全部属于 **task08**；
      本 task 只暴露"动作控制权被占用"的挂起接口）
- ❌ 不做设置窗口（**`idle_seconds` 的滑块界面属于 task11**；本 task 只要"读配置立刻生效"）
- ❌ 不做尺寸控制栏（task09）、不做音效（task10，坐下音效）
- ❌ 不做双击跳跃手势本身（task10）——但**必须**接上"双击退出 manual"
- ❌ 不做隐藏呼出 / 自启 / 单实例 / 重启
- ❌ 不做"鼠标悬停在宠物上就张望"这类**额外**行为（清单里没有）
- ❌ 不把状态机写进窗口类（必须是**独立、可单独测**的纯逻辑对象）
- ❌ 不改素材、不改 `idle_seconds` 的界面量程（5–300 是 task11 的事；本 task 只保证下限 1）

## 6. 验收标准

- [ ] 启动后不动鼠标：**约 20 秒**后进 `waiting`（张望），**再过约 10 秒**进 `sit`（坐下）
- [ ] 在 `config.json` 里把 `idle_seconds` 改成 `5` → 重启后约 5 秒张望、约 **5 秒**后坐下
      （`max(5, 5×0.5) = 5`，验证下限生效）
- [ ] 把 `idle_seconds` 改成 `300` → 不再很快张望（确认"读的是配置值"而非写死的 20）
- [ ] 把 `idle_seconds` 改成 `0` / `-10` / `"很久"` → 判定**下限夹到 1 秒**或回退 **20 秒**（按约定），
      **不崩**
- [ ] `idle_seconds` 改动**不需要重启**：改文件后，下一次判定立刻用新值
- [ ] 静置过程中把鼠标**移到别的程序窗口上晃动** → 宠物**立刻站起**回 `idle`，并**重新计时**
- [ ] 光标**完全静止**（不碰鼠标）时：**1px 级别的抖动不会**把宠物拽起来（阈值 2px 生效）
- [ ] 刚启动时第一次看到光标，**不会**被当成"鼠标动了"（首帧按没动处理）
- [ ] 点 `坐下休息`：宠物坐下且**一直坐着**（鼠标乱动、等 5 分钟都不变）
- [ ] `manual` 坐姿期间点菜单 `站起来` → 站起回 `auto` 模式
- [ ] `manual` 坐姿期间**双击宠物** → 自动退出 `manual`（跳跃接线在 task10；本 task 至少不保持坐姿）
- [ ] `manual` 坐姿期间久置计时**不会**把它拽起来（例外的第①条）
- [ ] 悬起接口可用：临时把挂起标志置真（模拟"拖动中"）→
      静置计时**归零但不切动作**（例外的第②条，为 task08 留的接线点确实生效）
- [ ] 静置到 `waiting` / `sit` 时，**镜像记忆生效**：
      先在 `idle` 翻开镜像，然后静置到 `sit`：`sit` **不翻**；
      把 `sit` 也翻上后静置到 `sit`：`sit` **是翻的**
- [ ] 静置 30 分钟：不出现"计时漂移"（不会越来越早/越来越晚），CPU 正常（150 ms 轮询很轻）
- [ ] 退出程序后，光标轮询定时器**确实停掉**（无残留进程占用）
