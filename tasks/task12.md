# task12 · 全局热键：藏起来还能叫回来

## 1. 背景

- **task01–11 已完成**：窗口、配置与日志、素材加载、尺寸与控制栏、动画、右键菜单（含镜像）、
  拖动与命中、久置行为、音效与双击、**设置窗口**（含"呼出快捷键"那一行的控件骨架）。
- 本 task 把"**隐藏宠物**"和"**呼出快捷键**"真正接上：
  菜单 `隐藏宠物` 可用、设置窗口那一行解锁、全局热键注册与回退链落地。
- 这是**最危险的一节**：做错了表现是"桌宠藏起来之后再也叫不回来"。

> **开始前必须先读**：`agent.md`（热键相关约定与坑）、
> `迁移清单.md` 第一部分 §10（隐藏与呼出**全部条目**）、§15 的快捷键录入条目、
> 第三部分 3.4（AltGr）/ 3.5（**两套修饰键掩码数值不同**）/ 3.10（热键必须是组合）、
> 附录 B（报错文案）、附录 D 的 **D5**。

## 2. 本任务目标

运行后能看到：

1. 右键 `隐藏宠物` → 宠物**消失**（控制栏也一起消失）；用户数据、窗口、帧缓存、
   档位、位置**全部保留**（不是销毁重建）；
2. 按 **`Ctrl+Alt+Shift+P`** → 宠物**立刻回来**，并且**重新置顶**（仍然浮在最上层）；
3. 设置窗口里 `呼出快捷键` 那一行**可用了**：点右边按钮进入录入态，
   按一次组合即录入（`Esc` 取消，单独按修饰键不算，至少一个修饰键）；
4. 录入 **`Ctrl+Alt+P`** 并隐藏宠物后，按新组合能呼出；按**旧组合**不再有反应；
5. 故意先占用一个热键（用别的程序占用 `Ctrl+Alt+Shift+P`）再启动桌宠：
   它**沿回退链**依次尝试 `Ctrl+Alt+Shift+P` → `Ctrl+Alt+Shift+O` → `Win+Alt+P` →
   `Ctrl+Alt+F12` → `Ctrl+Shift+F12`；成功后**写回配置**并说明"原快捷键不可用，已改用 X"；
6. **一个都注册不上**时：菜单 `隐藏宠物` **禁用**并提示
   `没有可用的呼出快捷键，隐藏后将无法呼出。请先在「设置」里指定一个快捷键。`；
7. 换热键失败时**回滚到原来那个**（绝不落到"没有热键可用"）；
8. 退出程序后热键**彻底释放**：立刻重启桌宠，同一个组合**还能注册成功**。

## 4. 接口约定

### `HotkeyManager`（`deskpet.hotkey`）

| 符号 | 语义 |
| --- | --- |
| `CANDIDATES` | 回退候选链常量：`Ctrl+Alt+Shift+P` → `Ctrl+Alt+Shift+O` → `Win+Alt+P` → `Ctrl+Alt+F12` → `Ctrl+Shift+F12` |
| `register(preferred: str) -> RegisterResult` | 按候选链依次尝试；返回 `(combo 或 None, changed: bool, reason)` |
| `unregister()` | **彻底释放**；退出路径必须调用 |
| `hotkey_pressed` 信号 | 收到 `WM_HOTKEY` 时发出 |
| `parse_combo(text) -> int \| None` | 文本 → 系统热键注册用的修饰键掩码 + 主键 |
| `format_combo(mods, key) -> str` | 掩码 + 主键 → 展示文本（顺序固定 `Ctrl → Alt → Shift → Win`） |
| `combo_to_win_mods(...)` | **Qt 修饰键 → Win32 `MOD_*` 的唯一转换函数**（§3.5） |
| `DEFAULT_HOTKEY = "Ctrl+Alt+Shift+P"` | 与配置默认值**同源**（不许两处各写一份） |

**修饰键掩码（**不可混用**，见 §3.5）**：

| 用途 | Shift | Ctrl | Alt | Win |
| --- | --- | --- | --- | --- |
| 界面事件的状态位 | `0x0001` | `0x0004` | `0x0008` | — |
| 系统热键注册 | `0x0004` | `0x0002` | `0x0001` | `0x0008` |

- `Ctrl+Alt+Shift` 在系统热键里是 **`0x7`**（2|1|4），**不是** `0xF`；
- 注意：**`0x0004` 在事件状态位里是 Control，不是 Shift**；
- **转换只允许在一个函数里做**，其它地方不许手算。

### 组合校验（`parse_combo`）

| 规则 | 约定 |
| --- | --- |
| 必须含修饰键 | 至少一个 `Ctrl`/`Alt`/`Shift`/`Win`；**裸键不能做热键** |
| 只能有一个主键 | 两个主键 → 非法 |
| 非法输入 | 空串 / `Space` 等 → **报错**：`快捷键必须包含 Ctrl / Alt / Shift / Win 之一` |
| 展示顺序 | 固定 `Ctrl → Alt → Shift → Win` |
| 占用 | 注册失败 `1409` → 文案 `快捷键已被其他程序占用（错误 1409）` |

### 隐藏 / 呼出

| 项 | 约定 |
| --- | --- |
| 隐藏语义 | **保留状态不销毁**：窗口、帧缓存、档位、位置全部保留，呼出时**瞬时恢复**（省掉重新解码几十张 PNG） |
| 隐藏后收不到按键 | 隐藏后窗口**没有焦点**，键盘事件**不会送到它** → 呼出**只能**靠系统级全局热键 |
| 呼出 | 恢复可见并**重新声明置顶**（置顶属性可能被系统在隐藏期间丢弃） |
| 收到热键事件 | **分两拍处理**：先让出一次事件循环（`QTimer.singleShot(0, ...)`），再执行显示 |
| 轮询必须独立 | **不能挂在动画帧回调上**：窗口隐藏后精灵停帧、帧回调不再触发，热键就永远没人处理 |
| 轮询间隔 | 现状约定 **120 ms**——若走原生消息过滤器（D5），可升级为**事件驱动**并去掉轮询；**两种路线必须择一并在 agent.md 写死** |
| 组合 = None | **拒绝隐藏**（否则叫不回来）+ 提示文案 |
| 换热键失败 | **必须回滚到原来那个** |
| 退出时 | **彻底释放**（`UnregisterHotKey`），否则组合被本进程占着 |

**注意 Qt 的现实**：`QShortcut` 只在应用有焦点时有效，**不能**用来实现本节功能；
必须回到 Win32 `RegisterHotKey`（`ctypes`）+ 自建消息接收。

## 6. 验收标准

- [ ] 右键 `隐藏宠物` → 宠物与控制栏**都消失**；任务管理器里**进程仍在**
- [ ] 按 `Ctrl+Alt+Shift+P` → 宠物**立刻回来**，并且仍**置顶**（切到浏览器它还在最上层）
- [ ] 隐藏 → 呼出重复 20 次：**没有变慢**（证明状态被保留，不是重建窗口）
- [ ] 隐藏后**点桌面/切窗口**都不影响呼出能力（键盘事件收不到，只靠全局热键）
- [ ] 设置窗口里 `呼出快捷键` 行**可用**；点按钮进入录入态，按 `Ctrl+Alt+P` 被录入
- [ ] 录入时**单独按 Ctrl** → 不算录入完成，界面显示 `Ctrl…`
- [ ] 录入时按 `Esc` → 取消，**保留原快捷键**
- [ ] 录入空串 / 按 `Space`（无修饰键）→ 报 `快捷键必须包含 Ctrl / Alt / Shift / Win 之一`，原值保留
- [ ] 用 `Ctrl+Alt+P` 隐藏后呼出成功；按**旧组合** `Ctrl+Alt+Shift+P` **无反应**
- [ ] **AltGr 坑**：中文键盘布局下按 `Ctrl+Alt`（用 AltGr 输入 `@` 的键位）不会**多加**一个 Alt；
      若发现异常，记录到 agent.md（库/驱动差异）
- [ ] 模拟占用：先用别的程序/另一实例占住 `Ctrl+Alt+Shift+P`，再启动桌宠 →
      自动改用候选链里的下一个，**配置被写回**，并有"已改用 X"的说明
- [ ] 把候选链**全部**占住后启动：`组合 = None`，
      菜单 `隐藏宠物` **禁用** + 提示文案与附录 B 一致
- [ ] 已验证"换热键失败会回滚"：注入一次注册失败 → 旧组合仍然有效
- [ ] 退出程序后：立刻重启桌宠，**同一个组合能注册成功**（说明退出时释放干净）
- [ ] 用任务管理器**强杀**进程后再启动：若组合注册失败，说明强杀路径没释放——
      记录到 agent.md（属系统行为，需说明取舍）
- [ ] 隐藏期间 CPU 占用**接近 0**（没有 120 ms 轮询在空转，或轮询成本可忽略）
- [ ] 隐藏 → 呼出后**动画继续正常播放**（帧回调恢复了）
