## 2. 本任务目标

运行 `python run.py` 后看到：

1. 屏幕右下角（距边缘 24 逻辑单位）出现一个 **250 × 250 左右的无边框窗口**；
2. 窗口里画着一个**占位图形**（一块纯色圆角矩形或一个显眼的方块即可）——
   **它周围的区域必须是真正透明的**：能看到并点到下面的桌面/其它窗口）；
3. 窗口**没有标题栏、不在任务栏里、始终置顶**（切到别的窗口它仍浮在最上面）；
4. 用鼠标**按住占位图形拖动**，窗口跟着走（不要用系统标题栏拖）；
5. 按 `Esc` 或 `Ctrl+Q` 能**干净退出**（进程消失、无残留）；
6. 控制台/日志里能看到一行启动信息（窗口位置、尺寸）。

## 4. 接口约定

**命名**：包名 `deskpet`，仓库/项目名 `deskPet`（见 `agent.md` 的命名规则）。

| 符号 | 位置 | 签名 / 语义 |
| --- | --- | --- |
| `run(argv=None) -> int` | `deskpet.app` | 唯一入口。创建 `QApplication`、建窗口、进事件循环，返回退出码 |
| `PROGRAM_NAME` | `deskpet` | 程序名常量（`"deskPet"`），供窗口标题/后续日志用 |
| `PetWindow(QWidget)` | `deskpet.pet_window` | 主窗口。本 task 只要求：`show()` 后出现在缺省落点、可拖动、可退出 |
| `PetWindow.showing_at_default_position()` | 同上 | 首次显示时按"贴屏幕右下角 + 24 逻辑单位边距"摆放 |
| `PetWindow.drag_by(dx, dy)` | 同上 | 用**自己记的基准位置**算位移（**禁止**回读窗口实时坐标） |

**窗口属性（本 task 的核心契约）**：

- `Qt.FramelessWindowHint`（无边框）+ `Qt.WindowStaysOnTopHint`（置顶）+ `Qt.Tool`（不进任务栏）。
- **透明（已定案 D1）**：素材将是**透明背景 PNG**（用户重做素材提供）。
  本 task 用占位图形，配 `setAttribute(Qt.WA_TranslucentBackground)` 让占位图形外真透明；
  **运行时不需要任何色键处理**。
- **点击穿透（已定案 D2 = `setMask`）**：本 task 就要把机制搭起来，不要留到以后：
  - 占位阶段：按占位图形的**不透明像素**生成一个 `QRegion` 并 `setMask(region)`；
  - **唯一入口**：`PetWindow.apply_mask(image)`（或等价的独立方法），
    **不要**把区域生成写死进事件处理器；
  - 降级：区域算不出来 / 图为空 → **不设遮罩**（整帧可点），**永不抛异常**；
  - 已知代价（**已接受**）：`QRegion` 是二值无抗锯齿的 → **人物边缘会有锯齿**。
    本 task 只需**观察并记录**这个观感（写进 `agent.md`），不需要解决。
- 坐标系：位移用 `event.globalPosition()`；命中判定用 `event.position()`
  （**两者不可混用**，见 `迁移清单.md` 第一部分 §5 的标注）。

**拖动状态（本 task 只需最小版）**：记住"鼠标在窗口内的偏移"，移动时用
`基准位置 + (当前全局坐标 − 按下时的全局坐标)` 得到新位置。

**信号**：本 task **不新增对外信号**。后续 task 再把位置变化等暴露成信号。

**启动参数**：本 task **只支持"能退出"的最小集**——`--help` 与（推荐）`--exit-after <秒>`
（用于无头/自动验证时能自动退出）。**不要**提前实现 `--pet` / `--position` / `--size-level`。

## 8. 实现补充（task01 完成后回填，以实现为准）

四条契约在实现时才暴露出来，**后面的 task 直接沿用，不要再试一遍**：

1. **必须显式 `setAttribute(Qt.WA_QuitOnClose, True)`**。
   Qt **不为 `Qt.Tool` 窗口设 `WA_QuitOnClose`**（实测为 `False`），而 `Qt.Tool` 不计入
   "最后一个主窗口" → `close()` 之后 `app.exec()` **不返回**、进程留在后台，
   §6 的"按 Esc 退出后进程确实结束"**做不到**。（实测：不设时 exec 一直不返回。）
2. **`drag_by(dx, dy)` 的 `dx/dy` 是"相对按下点的累计位移"，不是相邻增量**。
   按下时把当时的权威位置存成拖动基准，`drag_by` 内部按 `拖动基准 + (dx, dy)` 摆放。
   按增量累加会把窗口越拖越飞。§4 那句"`基准位置 + (当前全局坐标 − 按下时的全局坐标)`"
   就是这个意思，这里把它钉死。
3. **`QPainter` 会按 paint device 的 `devicePixelRatio` 缩放坐标系**。
   画到带 DPR 的 `QImage` 上时坐标一律用**逻辑单位**；自己再乘一遍 ratio 就是缩放两次
   （实测：250 逻辑单位的占位图被画成 313 逻辑单位、右下角被切掉；只在缩放 ≠ 100% 时显形）。
   **正确顺序**：先 `setDevicePixelRatio()` 再用逻辑坐标画，或者画完之后才标注 DPR。
4. **`QWidget` 没有 `hasMask()`**；要问 `mask()`，`mask().isEmpty()` 才是"没设遮罩"。

**验证方式**（本文档原先只写"人工怎么看"，实际做成了自动化 + 真机事实）：

- `QT_QPA_PLATFORM=offscreen` 跑自检：遮罩形状 / 降级、DPR（1 / 1.25 / 1.5 / 2）几何不变、
  默认落点、拖动基准、Esc / Ctrl+Q —— 38 项全过。
  ⚠ **offscreen 插件不支持 `setMask`**，所以"点击穿透"它测不出来。
- 真平台跑一次窗口并截屏（2560×1440，100% 与 125% 各一次）：`GetWindowRgn` 返回 `3`
  （COMPLEXREGION）；`WindowFromPoint` 在**图形中心**返回本窗口、在**窗口四角**返回**别的窗口**
  → 真穿透。这才是"§6 占位图形以外的区域点不到宠物窗口"的**事实**，不是"我以为它穿透了"。
- 自检脚本与截屏脚本都是**临时**的（task01 §3 只允许那 7 个文件，且明确不许建 `tools/`），
  跑完即删；结论已回填本文件与 `agent.md`。
