# task09 · 尺寸控制栏：一条悬浮条，缩放时按钮不动

## 1. 背景

- **task01–08 已完成**：窗口、配置与日志、素材加载、10 级尺寸模块、动画、右键菜单（含镜像）、
  久置行为状态机、拖动与命中（拖动会发出 `drag_started` / `drag_finished` 信号）。
- 尺寸目前只能靠 `--size-level` 与配置文件改。本 task 加入**尺寸控制栏**：
  右键菜单的 `调整大小…` 从"禁用"变成"可用"，点开一条悬浮条，
  用 `−` / `+` / `×` 现场调档。

> **开始前必须先读**：`agent.md`
> 含 PySide6 布局标注）、§4（缩放硬规则）、§9（菜单项 `resize` 的行为与"重置静置计时"）、
> 附录 B（档位文字与按钮文字）、附录 C（控制栏高 / 间距 / 预留）。

## 2. 本任务目标

运行后能看到：

1. 右键菜单里 `调整大小…` **可点**了；点了之后宠物**上方/下方**出现一条悬浮条：
   `1.00x（6/10）  [−] [+] [×]`；
2. **右边缘与宠物右边缘对齐**（不是水平居中）；栏高 40、与宠物间距 8；
3. 点 `−` → 档位减 1，文字与宠物尺寸**同时变化**；点 `+` → 档位加 1；
4. 到第 1 级时 `−` **置灰**；到第 10 级时 `+` **置灰**；
5. **缩放过程中按钮位置完全不变**（可以连点 `+` 一路到 10 级而不用追鼠标）；
6. 控制栏打开时宠物**整体上移一个条带高度**，底边固定；
7. **拖动宠物**时控制栏**按增量平移跟随**（重算锚点会抖、会被裁）；
8. 点 `×` 关闭控制栏，宠物**放回原本贴屏幕底边的位置**（边距归零）；
9. 重复点 `调整大小…` → 返回**同一个**栏（幂等）；关闭后再打开正常；
10. 宠物在屏幕**最下方**（放不下）时，栏放到宠物**上方**；上方也放不下时贴屏幕上下缘；
11. 档位变化会**写进配置**（重启后仍是这个档位）。

## 4. 接口约定

### `ControlBar`（`deskpet.control_bar`）

| 符号 | 语义 |
| --- | --- |
| `ControlBar(parent=None)` | **独立顶层窗口**：`Qt.Tool` + `Qt.FramelessWindowHint` + `Qt.WindowStaysOnTopHint` |
| `set_level(level, total)` | 刷新文字与两个按钮的禁用态 |
| `level_up` / `level_down` 信号 | 用户点了 `+` / `−` |
| `closed` 信号 | 用户点了 `×` |
| `follow(dx, dy)` | **按增量平移**自己的位置（由 task08 的 `drag_started` / `drag_finished` 与位置变化信号驱动） |
| `place_relative_to(pet_rect, screen_rect)` | 决定放在宠物下方/上方/贴屏幕缘 |
| `BAR_HEIGHT = 40` / `GAP = 8` / `RESERVED = 40 + 8 + 4` | 常量（**只允许在这里定义一处**） |

**布局约定（必须照做）**：

- 用 **`QHBoxLayout`**：`QLabel`（档位文字）+ `QPushButton("−")` + `QPushButton("+")` + `QPushButton("×")`，
  `setFixedHeight(40)`；
- **不要**用绝对坐标摆放控件；**窗口自身的位置**才由代码算（这是窗口管理，不是布局）；
- 文字的字体渲染要**亲眼确认**：`−` 与 `×` 若显示成方框，改用 `QToolButton` 或换字符
  —— **但那属于"改用户可见文字"，要同步 `agent.md`**；
- 边界置灰用 `setEnabled(False)`。

### 行为契约（逐条实现）

| 项 | 约定 |
| --- | --- |
| 文字 | `{倍数:.2f}x（{档位}/{总数}）`，例如 `1.00x（6/10）` |
| 定位 | 优先宠物**下方**，**右边缘与宠物右边对齐**（**不是**水平居中） |
| 兜底位置 | 下方放不下 → 上方（仍锚定右侧）；上方也放不下 → 退化为**贴屏幕上下缘** |
| 跟随 | 宠物被拖动时**按增量平移**（**禁止**重算锚点：在屏幕边缘会被裁、来回拖会抖） |
| 缩放中不动 | 打开控制栏时把宠物整体**上移一个条带高度**并全程保持该底部边距，使宠物底边固定 → **按钮位置完全不变** |
| 预留高度 | `栏高 + 间距 + 4` |
| 关闭 | 收起控制栏并把宠物**放回原本贴屏幕底边的位置**（边距归零） |
| 幂等 | 重复打开返回**同一个**栏；关闭后再打开正常；`−`/`+` 到边界返回"**没有变化**" |
| 用户显式指定位置时 | 底部边距机制**不生效**（位置由用户决定） |
| 菜单项 | `调整大小…` 切换控制栏，并**重置静置计时** |

**切档顺序硬约束**：**先重建该档的帧，再改窗口尺寸**（反了会短暂留白或裁边）。

**档位变化 → 写配置**：只在**换档时**写 `size_level`（`−`/`+` 到边界返回"没有变化"时**不写**）。
