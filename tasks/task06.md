# task06 · 右键菜单：换动作、休息/站起来、镜像翻转（按状态记忆）

## 1. 背景

- **task01–05 已完成**：透明置顶窗口、配置与日志、素材加载、10 级尺寸、
  动画播放引擎（循环/往返/一次性 + `frame_ms` 来自素材）。
- 现在动作只能靠命令行 `--action` 指定。本 task 加入**右键菜单**，
  并实现本次修订的**新增功能：镜像翻转**（清单第一部分 §9）。
- 注意：菜单里的"**调整大小…**"与"**设置…**""**隐藏宠物**"在本 task **尚不可用**，
  按约定**禁用而不是隐藏**（保持菜单位置稳定）。

> **开始前必须先读**：`agent.md`（信号命名规则、`mirror` 配置字段）、
> `迁移清单.md` 第一部分 §9（右键菜单 + 镜像翻转全部条目）、
> 第二部分 §4（`mirror` 字段细节）、第三部分 3.20（**换帧/换档/换镜像后衍生数据必须失效**）、
> 附录 B（用户可见文字清单，**不可随意改写**）。

## 2. 本任务目标

运行后能看到：

1. **在宠物身上点右键**，在鼠标处弹出菜单，项目依次是：
   `调整大小…` / `坐下休息`（或 `站起来`） / `镜像翻转` / `设置…` / `隐藏宠物` / 分隔线 / `退出`；
2. 其中 `调整大小…`、`设置…`、`隐藏宠物` 显示为**灰色不可点**（不是消失）；
3. 点 `镜像翻转` → 宠物**立刻左右翻转**（`idle` 时就是待机动作被水平镜像），
   并且菜单项**显示为已勾选**；
4. 再点一次 → 翻回来，勾选取消；
5. 切换动作来回验证记忆：`idle` 翻着 → 切到 `rest`（**不翻**）→ 切回 `idle`（**仍然是翻的**）；
   `rest` 单独翻过之后也能各自记住；
6. **关掉程序再启动**：上次翻过的状态**还在**（写进了 `config.json` 的 `mirror`）；
7. 点 `坐下休息` → 宠物进入 `rest` 动作并播放音效（音效属于 task10，本 task 只切动作），
   菜单文字变成 `站起来`；再点 → 站起来回到 `idle`；
8. 当前动作**不在适用范围内**（如 `running_left` / `waving`）时，
   `镜像翻转` 项显示为**灰色不可点**；
9. 按 `Esc` 或点菜单外关闭菜单，**不做任何事**；拖动途中点右键，菜单**不应打断拖动**。

## 4. 接口约定

### 菜单（`deskpet.context_menu`）

| 符号 | 语义 |
| --- | --- |
| `MENU_ORDER` | 有序列表，元素含稳定 id 与文字：`resize` / `action` / `mirror` / `settings` / `visibility` / `(separator)` / `quit` |
| `build_menu(parent, state) -> QMenu` | **每次弹出前重建**（数据驱动）；勾选态/禁用态按**当前状态**决定 |
| `action_id(action: QAction) -> str` | 稳定 id 用 `QAction.setData(id)` 承载，**不靠菜单文字** |
| `MenuState` | 传入的状态：当前动作、是否 manual 坐姿、尺寸栏是否已开、镜像是否开启、哪些项可用 |

**行为契约（逐条实现）**：

| 项 | 约定 |
| --- | --- |
| 定位 | **鼠标处**（`QContextMenuEvent.globalPos()`） |
| 层级 | 菜单**必须以宠物窗口为 parent**，否则跟随置顶会丢 |
| 未接线项 | `setEnabled(False)`，**不是隐藏** |
| 关闭 | 点菜单外或 `Esc` → 关闭且**不做任何事** |
| 文字切换 | 选中 `坐下休息` 后文字变 `站起来`，再选回来（**id 始终是 `action`**） |
| 菜单项文字 | 必须与**附录 B** 完全一致：`调整大小…` / `坐下休息` / `站起来` / `镜像翻转` / `设置…` / `隐藏宠物` / `退出` |
| 拖动中 | 右键**不得**打断拖动（拖动状态优先；或明确忽略拖动中的右键，并在 agent.md 记下选择） |

### 镜像（`deskpet.mirror` + `rendering`）

| 符号 | 语义 |
| --- | --- |
| `MIRRORABLE = ("idle", "waiting", "rest")` | **适用范围**（清单 §9）：待机 + 休息两类状态。<br>**2025 命名定案**：`sit` → `rest`，所以这里也改了（`agent.md` §2.5 / D12）。**真值现在住在 `config.MIRROR_STATES`**，task06 直接引用它，**不要另抄一份** |
| `MirrorState(config_store)` | 持有"状态名 → 是否翻转"的映射 |
| `is_on(action: str) -> bool` | 查询；非适用范围一律返回 `False` |
| `can_mirror(action: str) -> bool` | 当前动作是否可镜像（决定菜单项是否禁用） |
| `toggle(action: str) -> bool` | 翻转当前状态；**写回 `config.json` 的 `mirror`**；写失败 → 返回 `False`（**界面必须回滚勾选**，不能显示假成功） |
| `mirror_changed(action, on)` 信号 | 状态变化时发出，**渲染层据此重取帧** |

**渲染契约（最容易踩的一条）**：

- 镜像在**渲染层**做（`QImage.mirrored(horizontal=True)` 或等价物），
  **不生成新素材、不改 `asset.json`、不动原 PNG**；
- **帧缓存的键必须包含镜像维度**，否则"翻转后拿到未翻转的缓存图"（§3.20）；
- 镜像**不影响**锚点与档位（水平翻转折点对称，"右下角锚点不动"仍成立）；
- **命中判定必须一起镜像**（`x' = width - 1 - x`）——本 task 若判定尚未定案（D2），
  至少要在代码里留出"镜像后判定坐标怎么取"的**唯一入口**，并在 agent.md 里记下待接。

### 配置（`mirror` 字段）

- 形态：`{"idle": true, "rest": false}`（状态名 → 布尔）；
- 默认值 `{}`（**不写死三个 false**）；
- 写回时**按 `MIRRORABLE` 过滤键**（未知状态名不累积）；
- 键类型不对 / 值非布尔 → **丢弃该项 + 一条警告**，不影响启动；
- 配置整体坏掉 → 退化为"永远不翻转"，**不阻断启动**；
- **`mirror` 不得被"只保存已知键"的过滤逻辑当成未知键丢掉**。

- ❌ 不做音效（task10）
- ❌ 不做拖动与位置持久化（task08）

- ❌ 不改素材；**不要**通过"预先翻转 PNG"来实现镜像
- ❌ 不要给镜像做**三个独立菜单项**（只做一条 `镜像翻转`，按状态记忆）

- [ ] `调整大小…` / `设置…` / `隐藏宠物` **灰色不可点**（不是消失）
- [ ] 点 `Esc` 关闭菜单，宠物**没有任何变化**；点菜单外关闭，同样无变化
- [ ] 点 `镜像翻转`：宠物立刻**左右翻转**，菜单项**显示为勾选**
- [ ] 再点一次：翻回来，勾选取消
- [ ] 切到 `rest`（用 `坐下休息`）：`rest` **不翻**；切回 `idle`：**仍然是翻的**

- [ ] 关掉程序，检查 `data/config.json`：出现 `"mirror": {"idle": true, ...}`；

      两个非法项都被丢弃 + 警告；`running_left` **不会**被翻
- [ ] （**2025 新增**）手工把 `mirror` 写成 `{"sit": true}`（旧键名）→ 启动不崩，

- [ ] 把 `data/` 设成只读（或注入写失败桩）后点 `镜像翻转`：

- [ ] 点 `坐下休息` → 动作变 `rest` 且菜单文字变 `站起来`；再点 → 回 `idle` 且文字变回
- [ ] 菜单文字改一个（例如临时把 `镜像翻转` 改成 `翻转`）→ **接线仍然有效**
      （证明靠 id 不靠文字）；**验证完记得改回附录 B 的文字**
- [ ] 拖动过程中右键：要么菜单不弹，要么不打断拖动——**不能出现"拖一半停住"**
